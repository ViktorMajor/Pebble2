# Pebble

Pebble is a private two-person relational presence application built with React Native, Expo, TypeScript, Expo Router, and Supabase.

## Product governance

- [Product Constitution](docs/PRODUCT_CONSTITUTION.md) defines Pebble’s immutable product identity.
- [Design Principles](docs/DESIGN_PRINCIPLES.md) define stable experience and interaction guidelines while leaving implementation details mutable.
- [Decision Log](docs/DECISION_LOG.md) records accepted product and design changes and their consequences.
- [AGENTS.md](AGENTS.md) governs automated development behavior, conflict handling, verification language, and repository hygiene.

The authority order is Product Constitution, Design Principles, Decision Log, technical architecture documentation, then implementation code. Higher-authority documents win when guidance conflicts.
